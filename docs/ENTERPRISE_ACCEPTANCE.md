# Enterprise Acceptance Gates

Production deployment is not complete until all gates pass:

- Employee can contribute by saving ordinary work to approved OneDrive/SharePoint or Box locations.
- Employee can retrieve institutional memory through Claude without local software or developer access.
- Source-native permissions are enforced before model context.
- Current revision and supersession are resolved correctly.
- Source links/revisions/locations are preserved.
- Deleted or permission-revoked artifacts disappear from retrievable context.
- Box and Microsoft sources can coexist without identity or permission broadening.
- Connector and index health are observable by administrators.
- AI-created knowledge remains non-authoritative until human review.
- Licensed content is handled according to organizational rights and policy.
