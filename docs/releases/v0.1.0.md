# Collective Brain v0.1.0

First public pilot release of Collective Brain.

Collective Brain is an open shared-memory system for teams. It connects the files people already create in normal company storage so AI can retrieve what the team already knows with permissions, provenance, revision awareness, relationships, and human-governed contribution.

## What this release proves

- synthetic Employee X → Employee Y institutional-memory handoff
- retrieval without filename hints
- folder-root Brain identity
- Create Brain / Join Existing Brain product logic
- permission filtering before model context
- revision and authority handling
- Graphify-style relationship traversal
- source provenance
- advisory-only source boundaries
- snapshot freshness behavior
- pending-review AI knowledge proposals
- OneDrive/SharePoint and Box connector architecture and test coverage

## Maturity

This is a **pilot-stage open-source release**, not a finished production SaaS.

Real OneDrive/SharePoint, Box, identity/ACL revocation, and hosted AI integration must be validated in each organization's environment before using sensitive or controlled information.

Start with synthetic or non-sensitive pilot content.

## Core trust rules

- source permissions remain authoritative
- restricted information is filtered before AI context
- source-owned employee files are read-only by default
- stale evidence is refreshed or surfaced as stale when consequential
- AI-generated reusable knowledge remains pending review until human promotion

## Commercial adoption and support

Collective Brain is open source under Apache-2.0. Teams can adopt it themselves.

The maintainers can also help organizations with pilot design, deployment, storage/identity integration, governance, security validation, customization, training, and production hardening.
