# Employee Experience

Collective Brain should feel invisible.

An employee:
1. Creates a PowerPoint, Word document, Excel workbook, PDF, or other approved artifact.
2. Saves it to the normal shared OneDrive/SharePoint or Box location.
3. Continues working normally.
4. Later asks Claude a question.
5. Receives a grounded answer that can cite relevant organizational artifacts, revisions, and locations.

The employee does not manually tag every document, maintain a second wiki, run Graphify, or manage a vector database.
