# Rollout Model

## Employee
- Uses Claude.
- Creates normal Office work.
- Saves to approved OneDrive/SharePoint or Box folders.
- Asks questions in Claude.
- Does not administer connectors or infrastructure.

## Administrator
- Approves source locations.
- Configures centrally managed connector credentials.
- Maps identity and source permissions.
- Monitors indexing health.
- Assigns reviewers/SMEs.

## Reviewer / SME
- Reviews proposed reusable knowledge.
- Approves/rejects promotion.
- Owns authority/applicability decisions for controlled domains.
