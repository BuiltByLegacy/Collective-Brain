# V0 Exit Criteria

V0 is complete when CI proves:
- retrieval without filename hints,
- current revision preference,
- authority-aware grounded answer behavior,
- permission-negative filtering before model context,
- graph relationship context,
- source revision/location provenance,
- pending-review knowledge proposals,
- one-command Employee X -> Employee Y proof.

Production cloud connectors are explicitly deferred to P2.
