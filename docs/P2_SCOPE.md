# P2 Scope

P2 productionizes the proven V0 Brain for constrained enterprise environments.

## Deliverables
- Production OneDrive/SharePoint read-only connector
- Production Box read-only connector
- Source ACL and identity normalization
- Incremental sync and deletion/tombstone handling
- Hosted vendor-neutral Brain endpoint
- Claude skill/tool deployment requiring no employee-side developer access
- Connector/index health monitoring
- Admin-only configuration for approved sources and reviewers

## Out of scope
- Replacing OneDrive, SharePoint, or Box
- Requiring users to migrate documents into a proprietary repository
- Requiring employees to run local agents or CLI tooling
